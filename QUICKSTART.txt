POSTCONTROL SUITE — БЫСТРЫЙ СТАРТ (для проверки на боевом задании)
===================================================================

Архив два — выберите по операционной системе:
  PostControl_Suite_Package_Linux.zip    (Linux / macOS / сервер)
  PostControl_Suite_Package_Windows.zip  (Windows 10/11)
Содержимое идентично, отличается только набор wheel-пакетов в vendor.

Пакет самодостаточный: интернет НЕ нужен (все зависимости в папке vendor).
Данные не покидают компьютер: всё работает локально.

LINUX / macOS
-------------
  1. bash install.sh   <- один раз: ставит и запускает
  2. Открыть http://localhost:8000
  3. bash verify.sh    <- проверка на эталонных данных (PASS/FAIL)

MAC (окно приложения, без Docker)
---------------------------------
  1. Python 3.11+ с python.org (если ещё нет)
  2. В Терминале: bash install_mac.command   <- один раз (ставит всё и создаёт приложение SibDoc)
  3. Дальше: открыть «SibDoc» из Launchpad / Finder → Программы / Dock
     (в браузере: start_mac.command → http://127.0.0.1:8000)

WINDOWS
-------
  1. install.bat       <- двойной клик: ставит и запускает
  2. Открыть http://localhost:8000
  3. verify.bat        <- проверка на эталонных данных

Что нужно на компьютере: Docker Desktop ИЛИ Python 3.10+ (любой вариант).

ПОВСЕДНЕВНАЯ РАБОТА
-------------------
  start.sh / start.bat — запуск после перезагрузки
  В интерфейсе: Шаг 1 загрузить файлы -> Шаг 3 "Запустить проверку"
  -> скачать Excel и PDF.
  Параметры проверок: Шаг 2 в интерфейсе или файлы config\rules\*.yaml
  (применяются сразу, без перезапуска).

СКАНЫ ДЕКЛАРАЦИЙ (OCR) И ЯЗЫКИ
------------------------------
  Блок "Сканы деклараций" в интерфейсе: загрузите PNG/JPG/PDF сканы
  (RU/EN/ZH) -> система распознает поля, покажет предпросмотр с
  цветовой подсветкой статусов и выгрузит Excel для предпроверки.
  Язык интерфейса: кнопки RU / EN / 中文 в шапке.
  Паттерны полей: config\scan_fields.yaml, раскладка Excel:
  config\scan_mapping.yaml (расширяются без изменения кода).
  ВНИМАНИЕ: для OCR нужен системный бинарник Tesseract — в Docker-образе
  он уже внутри; при запуске через Python установите его отдельно
  (подробности — README.md, раздел "OCR"). Без Tesseract всё остальное
  работает полностью — недоступен только блок "Сканы деклараций".

ДОКУМЕНТАЦИЯ (папка docs)
-------------------------
  SPECIALIST_GUIDE.md — для специалиста пост-контроля
  AGENT_GUIDE.md      — для разработчика/агента (архитектура, расширение)
  DEPLOY.md           — развёртывание на сервере для команды

СТРУКТУРА ПАКЕТА
----------------
  app\        движок, проверки, DQ-детекция, API
  config\     конфигурация и правила проверок
  references\ справочники HS-кодов и элементов декларации
  data\       эталонные данные для проверки
  webui\      веб-интерфейс
  vendor\     офлайн-зависимости (не удалять!)
  storage\    сюда пишутся отчёты Excel/PDF
