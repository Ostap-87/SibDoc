# Демо-набор (вымышленные данные)

Создаётся `python3 tools/make_demo.py`. Все номера, компании, контракты и цены выдуманы;
номера контейнеров `DEMU…` — с правильной контрольной цифрой ISO 6346.

| Файл | Что это |
|---|---|
| `ru_dt/*.xml` | 6 ДТ РФ в формате ФТС (ESADout_CU, windows-1251) |
| `cn_dec_xml/*.xml` | 5 деклараций КНР 报关单 (DecMessage) |
| `cn_dec_demo.xlsx` | те же 报关单 таблицей с китайскими заголовками |
| `wide_table_demo.xlsx`, `purchase_demo.xlsx` | wide table и SAP |
| `sap_vs_cd_demo.csv` | ручная таблица (Windows-1251, разделитель «;») |

Заложенные расхождения:
1. ДТ …0000001 — всё совпадает.
2. ДТ …0000002 — цена в 报关单 ниже, чем в SAP и ДТ.
3. ДТ …0000003 — ДТ и SAP в USD, 报关单 в юанях: совпадает после пересчёта по курсу НБК (REVIEW).
4. ДТ …0000004 — вес в ДТ больше, чем в SAP и 报关单.
5. ДТ …0000005 — код в ДТ другой марки; контракт набран латиницей (засчитывается).
6. ДТ …0000006 — ДТ нет в SAP.
7. Декларации …0105 нет в ручной таблице; у …0102 в ручной таблице лишний пробел (засчитывается).
