# SibDoc 3 — новый проект на основе SibDoc 2.0.1

Решение пользователя 05.11.2026: «оставить старую версию как она есть и создать новую версию на основе старой — это
должен быть новый проект в новой версии, дополнения делаем в новой версии». Старая версия не меняется: репозиторий
`Ostap-87/SibDoc` (ветки `main` и `v2`, коммит `51eed5a`) и резерв `Ostap-87/sibdoc-versions` (ветка `v2.0.1`).
SibDoc 3 живёт в том же репозитории `Ostap-87/SibDoc`, в папке **`v3/`** ветки `main` (решение пользователя 05.11.2026:
«в этом репозитории сделай внутри папку под версию 3»); старая версия — корень репозитория, её файлы не меняются.
Все команды SibDoc 3 запускаются из папки `v3/`.

## Два режима работы (выбор на первом экране, переключение в любой момент)

1. **Работа с ретро данными — пост-контроль.** То, что уже есть в 2.0.1: проверка и сверка прошедших отгрузок,
   контрактов и деклараций (ДТ РФ, 报关单, SAP, справочники), отчёты.
2. **Работа с данными в реальном времени — ближайшие отгрузки.** Логика:
   скан декларации (PDF, JPG/PNG/TIFF, Word, Excel) → распознавание → таблица Excel →
   мэтч с системными данными (SAP / 1С / выгрузки) и справочниками (HS-коды, CDE, контракты) →
   мэтч с Excel-черновиком декларации → мэтч с Excel-справочниками и базой данных → список расхождений
   до подачи / отгрузки.

На первом экране — выбор режима и **типа документов**, с которыми идёт работа (ДТ РФ, 报关单, черновик,
инвойс, упаковочный лист, транспортные документы, сертификаты, контракты, выписки банка). Переключение
между двумя экранами — без потери загруженного.

## Пакетная загрузка

Массив документов одним действием: архив ZIP, PDF (в т. ч. многостраничный), Excel, Word, картинки и любой
другой формат. Пакет из 20–30 документов распознаётся сразу: тип каждого документа определяется
автоматически (с возможностью поправить вручную), поля извлекаются, документы попадают в систему и дальше
проверяются и сверяются с уже имеющимися данными.

## Закрытый контур

Инструмент работает без интернета: распознавание локально (Tesseract с rus / eng / chi_sim в комплекте),
никаких внешних сервисов и CDN в интерфейсе, курсы валют — ручные или из файла, установка из локального
комплекта библиотек (wheelhouse), без телеметрии.
