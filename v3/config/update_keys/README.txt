SibDoc3: закрытый контур — доверенные ключи «Обновления с носителя».

Положите сюда открытые ключи Ed25519 (*.pub: base64 32 байт или PEM), которыми подписывают
архивы обновлений (tools/make_update_package.py --gen-key / --sign). Архив с подписью SHA256SUMS.sig
принимается, только если подпись подходит к одному из ключей этой папки. С
offline.update.require_signature: true (config/system.yaml) архивы без подписи не принимаются.
Закрытый ключ (*.key) сюда НЕ кладите. Подробно — docs/OFFLINE.md, раздел 7.
