# SibDoc 3 (на основе SibDoc 2.0.1 · PostControl Suite)

> **SibDoc 3 — новый проект.** Два режима: пост-контроль прошедших отгрузок (ретро) и проверка ближайших отгрузок
> в реальном времени; пакетная загрузка документов; работа без интернета. План — [`docs/ROADMAP_v3.md`](docs/ROADMAP_v3.md).
> Код SibDoc 3 — папка `v3/` репозитория `Ostap-87/SibDoc` (все команды — из неё); версия 2.0.1 без изменений —
> корень репозитория и ветка `v2`, резерв — `Ostap-87/sibdoc-versions`.

Пост-контроль таможенных деклараций на маршруте Россия → Китай: сверка китайских деклараций
(报关单 / CD), российских ДТ, данных SAP и всего пакета документов отгрузки. Восемь проверок
(цена, HS-код, условия поставки, элементы декларации, контракт, полнота, сквозная
«ДТ ↔ 报关单 ↔ SAP», «Пакет документов»), проверка качества данных, курсы ЦБ РФ и НБК (CFETS),
журнал событий, коннекторы, отчёты Excel и PDF (RU + ZH).

**Новое в 2.1 — «Весь пакет ВЭД».** Четыре новых слота: коммерческий инвойс, упаковочный лист,
транспортный документ (CMR, коносамент B/L, накладная СМГС, авианакладная AWB) и сертификаты
(соответствие ЕАЭС, происхождение СТ-1 / Form A / Form E / CO). Файлы — Excel/CSV (строка на позицию,
шапка документа в колонках или блоком над таблицей), PDF с текстовым слоем и сканы. Проверка
«7. Пакет документов» собирает документы в отгрузки по номеру инвойса и контейнерам и сверяет
комплект, инвойс ↔ упаковочный лист, инвойс ↔ ДТ / 报关单 (номер, сумма, валюта, условия),
упаковочный лист ↔ накладная (места, брутто, контейнеры, пломбы), ссылки ДТ на накладную и
сертификаты (срок действия на дату ДТ, код ТН ВЭД, страна происхождения). Пояснения — по-русски
и по-китайски. Демо: `data/demo/package/`; подробно — `docs/SPECIALIST_GUIDE.md`, раздел 3, «7. Пакет документов ВЭД».

**Выписки банков и оплаты (из ветки 2.2):** слот «Банк: выписки» принимает файлы, которые бухгалтер уже
получает, — 1С «Клиент-банк» (`kl_to_1c.txt`), ISO 20022 camt.053, SWIFT MT940, CSV/Excel
интернет-банков КНР и РФ; проверка «8. Оплаты» связывает платежи с контрактами (номер в назначении,
инвойс, контрагент, валюта, сумма). Коннекторы РФ–Китай сообщают статус «работает» / «работает через
выгрузки» / «нужен доступ: что и у кого»: 1С (OData и EnterpriseData), Kingdee и Yonyou (проверено на
эмуляторе), Единое окно КНР и ЭТРАН (через выгрузки). Подробно — `docs/CONNECTORS.md`.

**На Mac (окно приложения «SibDoc 3», отдельно от старой версии):** скачайте репозиторий `Ostap-87/SibDoc`
(Code → Download ZIP), распакуйте и в Терминале выполните `bash ~/Downloads/SibDoc-main/v3/install_mac.command` — появится
приложение «SibDoc 3» в ~/Applications и значок «SibDoc 3» на рабочем столе (порт 8030, журнал `~/Library/Logs/SibDoc3.log`).
Старое приложение «SibDoc» (версия 2.0.1 из корня репозитория) остаётся как было. Нужен Python 3.11+ с python.org.
Если pypi.org отвечает медленно (Китай, часть сетей в России), установщик сам берёт библиотеки с зеркала
(Цинхуа или Alibaba); своё зеркало: `PIP_INDEX_URL=<адрес> bash install_mac.command`.
В браузере вместо окна: `start_mac.command` → http://127.0.0.1:8030.

**Как проверить за 10 минут** (на демо-данных, без своих документов):
1. Откройте «SibDoc 3» → первый экран «С какими данными работаем?».
2. «Реальное время» → перетащите `data/demo/package/Пакет_документов_отгрузка_0000117.zip` → 26 документов распознаются
   сами → «Проверить отгрузку» → таблица OK / REVIEW / ISSUE (на демо: 36 строк, 29 / 1 / 6) → «Скачать Проверка отгрузки.xlsx».
3. Переключатель в шапке «Ретро данные» → «Загрузить пакет документов» → «Добавить в сверку» → «Проверить» → проверки 1–8,
   отчёт Excel / PDF.
4. Без интернета: выключите Wi-Fi и повторите шаги 2–3 — всё работает; в шапке «Закрытый контур: интернет не используется».
   Интернет нужен только один раз — при установке (библиотеки и Tesseract) или комплект для установки без сети (`docs/OFFLINE.md`).
Установщик кладёт значок «SibDoc 3» на рабочий стол и ставит распознавание сканов (Tesseract) готовой сборкой
conda-forge в папку `.ocr` (~200 МБ, без Homebrew; отдельно — `bash install_ocr_mac.command`).
Обновить уже установленный SibDoc 3 (берётся только папка `v3/` репозитория; `.venv`, `.ocr` и `storage` сохраняются):

```bash
cd ~/Downloads/SibDoc-main/v3 && curl -fsSL https://codeload.github.com/Ostap-87/SibDoc/tar.gz/refs/heads/main \
  | tar -xzf - --strip-components=2 '*/v3/*' && bash install_mac.command
```

**SibDoc3: закрытый контур (без интернета).** По умолчанию программа не обращается в интернет
(`config/system.yaml → offline`, `SIBDOC_OFFLINE=0|1`); разрешены только адреса внутри контура
(`offline.allow_hosts`: локальная сеть, сервер 1С, база данных). В шапке — «Закрытый контур: интернет не
используется». Курсы — файлами ЦБ РФ / CFETS / шаблоном («Курсы валют» → «Курсы из файла»), справочники
и правила — «Обновление с носителя». Комплект для установки без интернета собирается на компьютере с
интернетом: `bash tools/make_offline_bundle.sh --platforms windows,linux-x86_64 --with-ocr --with-python`,
в контуре — `bash install.sh --offline wheelhouse` (`install.bat`, `install_mac.command` — так же).
Подробно — [`docs/OFFLINE.md`](docs/OFFLINE.md).

**Два режима (SibDoc 3).** Первый экран — выбор: **«Ретро данные»** (пост-контроль прошедших отгрузок,
контрактов и деклараций) или **«Реальное время»** (проверка ближайших отгрузок до подачи), и типы документов,
с которыми идёт работа (ДТ РФ, 报关单, черновик, выгрузка SAP / 1С, инвойс, упаковочный лист, транспортные
документы, сертификаты, контракты, выписки банка, справочники; выбор запоминается для пользователя). В шапке —
переключатель режимов: загруженное не теряется. Ретро — прежний пост-контроль (невыбранные источники свёрнуты в
«Другие источники») плюс «Загрузить пакет документов» → «Добавить в сверку»; реальное время — пакет (ZIP,
перетаскивание, прогресс по файлам), типы с правкой, источники проверки, «Проверить отгрузку», фильтр OK /
REVIEW / ISSUE, причины RU + 中文, Excel. Снимки — `docs/screens/`, подробно — `docs/REALTIME.md` §8а и
`docs/SPECIALIST_GUIDE.md` §0.

**Сканы деклараций (OCR):** PNG/JPG/TIFF/PDF-сканы ДТ и 报关单 на русском, английском и китайском;
демо — `data/demo/scans/` (`python3 tools/make_demo_scans.py`). Tesseract ищется в `SIBDOC_TESSERACT`, `.ocr/bin`,
PATH, Homebrew, MacPorts; языки — из папки `tessdata` программы (rus, eng, chi_sim).

**Реальное время и пакетная загрузка (SibDoc 3):** пакет из 20–30 документов одним действием — ZIP (с
вложенными папками и архивами), PDF (несколько документов в одном файле делятся по страницам), Excel, Word
(.docx; .doc — через LibreOffice), картинки (OCR), XML, TXT, письма EML. Тип каждого документа определяется
по правилам `config/intake/classify.yaml` (с объяснением, правится вручную), поля — в единую таблицу
«Пакет.xlsx» с источником и уверенностью каждого значения. Проверка ближайшей отгрузки: декларация со скана ↔
черновик ↔ SAP / 1С ↔ справочники ↔ БД → «Проверка отгрузки.xlsx» (OK / REVIEW / ISSUE, причины RU + 中文).
Без интернета. API `/api/intake/*`, `/api/realtime/*`; демо — `python3 tools/make_demo_package.py`;
подробно — [`docs/REALTIME.md`](docs/REALTIME.md).

**Запуск:** `pip install -r requirements.txt && uvicorn app.server:app --port 8000` → http://localhost:8000
(или `docker compose up -d`). Вход выключен (прототип): `config/system.yaml → auth.disabled`.

**Проверка:** `./verify.sh` (эталон + демо-набор), `pip install -r requirements-dev.txt && pytest`.

**Без сервера:** `python3 run_cli.py --wide … --purchase … --ru-dt "dt/*.xml" --cn-dec 报关单.xlsx`
(пакет ВЭД: `--invoice … --packing … --transport … --conformity …`, можно маски «*.xlsx»;
выписки банка — `--bank "выписки/*"`, реестр договоров — `--contracts EnterpriseData.xml`).

Настройки: `config/system.yaml` (источники, проверки, коннекторы), `config/rules/*.yaml`
(параметры проверок, без перезапуска; пакет ВЭД — `docs_package.yaml`), `config/fields.yaml` (словарь полей),
`config/xml_profiles.yaml` (теги XML деклараций), `config/rates.yaml` (курсы).
Демо-набор из вымышленных данных: `data/demo/` (`python3 tools/make_demo.py`; выписки банков,
1С EnterpriseData и выгрузка 单一窗口 — `python3 tools/make_demo_bank.py`).
Рабочие данные (`storage/`) в репозиторий не попадают.
